# Cuentas Claras

App de gastos compartidos para parejas. PWA estática (GitHub Pages) + Supabase (Postgres, Google Auth, Row Level Security).

> Cuentas claras conservan la amistad... y el matrimonio.

## Estado

En construcción. Plan y avance en la carpeta de documentación del proyecto (`docs/estado.md`, fuera de este repo).

## Configuración local

1. Copiar `.env.example` a `.env` y completar los valores.
2. `.env` nunca se sube: los secretos de producción van en GitHub Secrets.

## Montos

Todo se guarda en centavos enteros. ARS y USD se calculan por separado y nunca se mezclan.
